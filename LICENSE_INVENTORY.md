## Exact selected weight

- URL: https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2net.onnx
- Size: 175,997,641 bytes
- Upstream MD5: `60024c5c889badc19c04ad937298a77b`
- Independently computed SHA-256: `8d10d2f3bb75ae3b6d527c77944fc5e7dcd94b29809d47a739a7a728a912b491`
- Model authors: Xuebin Qin, Zichen Zhang, Chenyang Huang, Masood Dehghan, Osmar R. Zaiane, Martin Jagersand. U²-Net: Going Deeper with Nested U-Structure for Salient Object Detection, Pattern Recognition 106 (2020), 107404.
- ONNX distribution attribution: Daniel Gatis and rembg contributors.

Runtime and build transitive distributions are enumerated from the locked environment in `licenses/dependency-inventory.json`; their shipped license files are retained under `licenses/dependencies/`. These include coloredlogs (MIT), humanfriendly (MIT), flatbuffers (Apache-2.0), protobuf (BSD-3-Clause), sympy (BSD-3-Clause), mpmath (BSD), packaging (Apache/BSD), and Windows runtime/build helpers. The lockfile is the authoritative dependency graph. Some metadata contains full license text instead of an SPDX identifier; retained texts govern.

Qt's source-tag component attribution manifests and 148 license/notice files are retained in `licenses/qt-6.10.0/`, with exact source URLs in its manifest. These include notices for third-party code bundled by Qt (not every listed component is enabled in this Windows build). Source repository tags: qtbase, qtimageformats and qtsvg `v6.10.0`. The custom packaging hook omits unused Qt PDF and virtual-keyboard plugins before DLL dependency collection; the final package contains only Qt Core, Gui, Network, Svg and Widgets. Qt Virtual Keyboard has GPL/commercial licensing and is deliberately excluded, along with its QML dependency chain.

The app does not redistribute proprietary system fonts, marketplace logos, dealer plate artwork or customer uploads. Users must have rights to assets they import. No marketplace-specific size requirements are asserted.
