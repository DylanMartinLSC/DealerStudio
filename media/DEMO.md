# Real DealerStudio recording

Fresh captures from the actual packaged Windows application, controlled through the Windows UI. The real Camry CPU-offline verification project was copied into a separate recording directory and opened normally. The GIF shows Original, Result, Comparison and a live switch to the dark studio.

These are selected actual window frames paced into a nine-second GIF, not a continuous inference-timing recording. The mask was precomputed by the real local ONNX model and includes the existing manual corrections/plate treatment. No UI, segmentation or vehicle pixels were fabricated. Review limitations remain in the README.
