# README example image

`studio-example.png` is a derivative of **2018 Toyota Camry LE front 6.13.18.jpg**, photographed by **Kevauto** on 13 June 2018.

- Source: https://commons.wikimedia.org/wiki/File:2018_Toyota_Camry_LE_front_6.13.18.jpg
- Original image license and derivative license: **CC BY-SA 4.0**, https://creativecommons.org/licenses/by-sa/4.0/
- Changes: local U²-Net background segmentation, a small manual background-corner mask stroke, resizing and reframing onto an original neutral studio, a manual solid plate rectangle and manually specified tire-contact shadows. Source paint, reflections, badges and visible condition markings remain.
- The derivative was produced by the real application pipeline and copied from `verification/output/reviewed.png`; it is not an ImageGen mockup.

The screenshot shown in the README, `verification/packaged-ui.png`, also displays Kevauto's vehicle photograph processed by the app. The photographic content and derived screenshot carry this attribution and CC BY-SA 4.0; the original application UI/code has its separate Apache-2.0 license.
